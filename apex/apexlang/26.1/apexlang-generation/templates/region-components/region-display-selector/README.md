# Region Display Selector Templates

## Purpose
Canonical guidance for the native `regionDisplaySelector` region family. An RDS has no data source; it controls an explicit set of sibling page regions that opt in through `advanced.regionDisplaySelector: true`.

## Usage
- Load `region-display-selector._common.md` first to align variable contracts, guardrails, and required inputs.
- Load `region-display-selector.standard.md` for the canonical View Single Region example.
- Load `region-display-selector.permutations.md` when selecting or testing mode, icon, Show All, or persistence combinations.
- Follow `references/domains/page-components/regions/region-display-selector/workflow-region-display-selector.md` for controller/target selection and validation rules.
- Preserve canonical path references and markdown-first conventions when updating workflow or registry links.
