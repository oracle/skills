# Timeline Templates

Canonical Universal Theme Timeline template-component guidance.

## Usage

- Load `timeline._index.md` first.
- Load `timeline._common.md` for the shared generation contract.
- Load `timeline._template_options.md` only when validating Timeline attributes or enum values.
- Choose the report sample or a single permutation branch after the source mappings are proven.
- Follow `references/domains/template-components/timeline.md` for compiler authority and unsupported metadata.
